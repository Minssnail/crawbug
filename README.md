# 《网络爬虫技术》智能教材（Web Scraping & Data Acquisition for AI）

面向高等职业院校**人工智能技术应用专业（专科）**开发的交互式智能教材，系统讲授互联网数据合规采集、动态网页逆向解析、高性能异步与分布式爬虫架构，以及面向大语言模型（LLM）预训练、指令微调（SFT）与检索增强生成（RAG）的高质量语料工程全流程。

- **在线阅读地址（GitHub Pages）**：<https://minssnail.github.io/crawbug/>
- **核心规模**：全书共 **12 章**、覆盖 **240 个知识图谱概念（DAG）**、配套 **25 个交互式微仿真（MicroSim）实验规格**，正文中文汉字逾 **10.7 万字**。
