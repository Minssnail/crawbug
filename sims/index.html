    交互式微仿真实验目录（List of MicroSims）¶

    本页面汇总了《网络爬虫技术》全书 12 章设计的 25 个交互式微仿真（MicroSim）实验规格。每个微仿真均严格对齐 2001 修订版布鲁姆教育目标分类学（Bloom's Taxonomy），帮助学生通过可视化交互攻克核心原理与工程重难点。

    所属章节 MicroSim ID (sim-id) 微仿真实验名称 布鲁姆认知层级 推荐实现库

    第 1 章 crawler-bfs-dfs-predictor 爬虫遍历策略预测器（BFS 广度优先 vs DFS 深度优先） Apply (应用) vis-network
    第 1 章 robots-compliance-auditor robots.txt 协议解析与合规风险沙盒 Evaluate (评价) p5.js
    第 2 章 http-status-header-triage HTTP 状态码与请求/响应头故障诊断台 Analyze (分析) p5.js
    第 2 章 http-lifecycle-session-inspector HTTP 全链路报文与 Cookie/Token 会话追踪仪 Understand (理解) p5.js
    第 3 章 python-http-request-builder Python HTTP 请求参数与载荷组装实验室 Apply (应用) p5.js
    第 3 章 session-backoff-simulator TCP 连接复用与指数退避重试模拟器 Evaluate (评价) Chart.js

    第 6 章 ch06-selenium-vs-playwright-arch Selenium 与 Playwright 通信架构及渲染生命周期对比器 Understand (理解) p5.js

    第 8 章 semaphore-token-bucket-limiter Semaphore 并发阀门与令牌桶（Token Bucket）平滑限流沙盒 Apply (应用) Chart.js
    第 9 章 etl-simhash-cleaning-workbench 脏数据 ETL 清洗流水线与 SimHash 海明距离去重实验台 Apply (应用) p5.js
